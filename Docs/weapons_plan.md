# The weapon plan (DRAFT - agreed direction, names can still change)

Every weapon in the game: the 2 starters, 60 Arcade Machine weapons (10 boss
packs x 6) and 16 event weapons (8 event bosses x 2). 78 in all.

## The rules

- **6 types, all melee:** Fists, Sword, Hammer, Daggers, Scythe, Katana. A
  weapon's normal attacks come from its TYPE (every sword swings the same way).
  What's unique per weapon is its look (a model) and ONE ability (a cooldown,
  about 10-15 s).
- **Each pack = one weapon of each type**, one per rarity: **Common, Rare,
  Epic, Legendary, Mythic, Secret** (Uncommon dropped: 6 weapons, 6 rarities).
  Which type gets which rarity is shuffled from pack to pack, so every type
  has a Secret somewhere and no type is "the best one".
- **Abilities grow with rarity - and stay modest until Mythic:**

| Rarity | Ability | How it's made |
|---|---|---|
| Common | one small effect for a few seconds, with an aura in the boss's colour | shared building blocks (code) |
| Rare | a slightly stronger or two-part version | shared building blocks (code) |
| Epic | a simple move: dash-strike, spin, ground slam, leap strike or uppercut, in the boss's theme | 5 shared moves, re-coloured |
| Legendary | its own themed move - noticeable, but not game-changing | unique (animation) |
| Mythic | a big, flashy unique move | unique (animation) |
| Secret | the showpiece: a unique attack, its own sounds, a server-wide banner when rolled | unique (animation) |

- **Building blocks** (mixed so no two weapons feel the same): damage up,
  lifesteal (heal a share of the damage you deal - never a plain heal: flasks
  are the heals), faster attacks, stamina refill, faster roll, damage taken
  down, a one-hit shield, a bigger next hit, stacks that burst, knockback,
  slow on the target, crit chance, move speed.
- **Rough numbers to start from:** Common buffs ~+15-20% for 4 s; Rare ~+25%
  or two effects; lifesteal 15% for 4-5 s; cooldowns 12-15 s. Mastery makes
  every ability a bit bigger or longer (Commons too - no weapon goes dead);
  mastery 100 awakens it (new look, stronger ability).
- **Launch with 5 packs: every second floor** (1 Slime, 3 Knight, 5 Speedway, 7 Jungle, 9 Canvas = 30 weapons), so the first roll comes right after the first boss. The even floors' packs (Cactus, Dojo, Neon, Garden, Throne) come as "NEW WEAPON PACK!" updates.

## Event weapons (from the event bosses)

Each event boss drops two: a **common** one (about 20-30%, Epic-level ability)
and a **very rare** one (about 0.5-1%, Mythic-level ability, the rarest trades
in the game), with an event pity counter. Three reuse the Blender swords we
already made (Ember Cleaver, Tidefang, Voidstar).

| Event boss | Common drop | Very rare drop |
|---|---|---|
| Magma Kongo | Ember Cleaver (Sword): a dash-strike leaving fire | Volcano Fists (Fists): punches erupt pillars of lava |
| Frostbloom Petalina | Frost Thorn Daggers (Daggers): dashes slow the target | Tidefang (Sword): a wave of ice spikes along the floor |
| Storm Kaze | Thunder Wraps (Fists): a lightning punch | Raijin Katana (Katana): quick-draw lightning that chains between enemies |
| Galaxy Oozark | Nebula Hammer (Hammer): a star-burst slam | Voidstar (Sword): a small black hole pulls enemies in, then bursts |
| Golden Burrowmore | Gilded Spade Scythe (Scythe): a gold spin that drops gems | Treasure Hammer (Hammer): a rain of gems on the target area |
| Nitro Revvington | Nitro Daggers (Daggers): a boost dash | Afterburner Scythe (Scythe): a spinning ring of flame |
| Shadow Tuber | Shadow Spine Katana (Katana): a shadow dash-slash | Nightmare Needles (Daggers): shadow spines burst up round the target |
| Glitch Gridlock | Pixel Scythe (Scythe): a glitchy sweep | Fatal Error (Katana): time freezes for a blink, then everything in front is cut |

## What has to be made

- **Models:** 76 weapon models (the 2 starters exist). In Blender, like the
  swords (`Tools/Weapons`).
- **Animations** (far fewer than 78 x a moveset, because types share swings):
  - per TYPE: idle + a 3-hit combo (+ the katana's quick-draw) = about 25
  - the 5 shared Epic moves = 5
  - one each for every Legendary, Mythic, Secret and very rare event weapon = 38
  - Commons and Rares need none (auras and effects are code)
  - about **68 animations** in all, made the way the sword's are
    (`Tools/Animations`: posed in Python on an exact R6 rig, exported as
    KeyframeSequences; Blender renders the previews).
- **Adding them without copying IDs by hand:** since October 2025 Roblox's
  Open Cloud Assets API can upload animations. So: one script uploads every
  exported animation (and weapon model) with an Open Cloud API key and writes
  all the new IDs into one file the game reads (`AnimationIds.lua`), which Rojo
  syncs. One command instead of 68 uploads and 68 copied IDs. **Built:**
  `Tools/Upload/upload_assets.bat` (the models and the abilities' animations;
  it copies the IDs, which go in `ReplicatedStorage/AssetIds.lua` - Windows
  wouldn't let it write into the project in Documents) and
  `Tools/Animations/upload_animations.bat` (the types' swings, IDs in Config).
  The 5 shared Epic moves were dropped: every weapon got its own ability
  instead (`ReplicatedStorage/Moves`).
